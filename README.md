A deterministic Python (stdlib only, no network) program that writes a single
one-line alien tourist review of Earth (at most 200 characters) to
`entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).

Run: `MAKEFUN_OUTPUT_DIR=/output python3 main.py`
